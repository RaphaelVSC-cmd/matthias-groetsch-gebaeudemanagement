# Matthias Grötsch – Gartenbau & Gebäudemanagement Regensburg

> **Immersive Studio Edition v4.0** – Hochwertige B2B-Webpräsenz mit Three.js 3D Scrollytelling, Lenis Smooth Scroll, GSAP ScrollTrigger, interaktivem Flächenrechner und 100% deutscher Rechtskonformität (§ 5 DDG & DSGVO Art. 13).

---

## 🌟 Highlights

- **Immersives 3D Scrollytelling:** Scroll-synchronisierte Explosionsdarstellung („The Layered Groundwork Exploded View“) in Three.js (Fundament ➔ Pflasterung ➔ Baumpflege & Winterdienst).
- **Mobile Zero-Collision Guard:** Kein Touch-Lock auf Smartphones, DPR auf 1.5 gedrosselt für stabile 60 FPS, Sticky Bottom-Bar auf `z-index: 99999`.
- **7-Säulen Master-Audit (100% GRÜN):** Vollständig geprüft nach `website-audit-pro`.
- **Rechtssicherheit nach § 5 DDG & DSGVO:** Barrierefreie Rechts-Modals, TDDDG Consent-Banner, Two-Click Google Maps (`data-src`) und keine externen Fonts (LG München I konform).
- **Conversion-Features:** Interaktiver Regensburger Projekt- & Flächenrechner, 3-stufiger Anfrage-Funnel, klickbare Direktruf-Buttons & WhatsApp Floating Widget.

---

## 🛠️ Tech Stack

- **HTML5:** Semantische Struktur mit ARIA Landmarks und Schema.org LocalBusiness + FAQPage.
- **CSS:** Tailwind CSS + maßgeschneidertes Design-System (`style.css`).
- **3D & Animationen:** Three.js (WebGL), GSAP, ScrollTrigger, Lenis Smooth Scroll.
- **JavaScript:** Vanilla JS für Rechner, Funnel, Consent Manager und Modal-System.

---

## 🚀 Schnellstart

### Windows
```cmd
start.bat
```

### macOS / Linux
```bash
chmod +x start.sh
./start.sh
```

Öffnen Sie anschließend `http://localhost:3000` im Browser.
